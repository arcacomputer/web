02 / Operating model

Human judgment at the center. Machines with real responsibility.

Work is split by role, handed off with context, bounded by permissions, and reviewed where errors carry consequence. The point is not more automation. It is accountable execution.

Input / 001 Human direction
Process / 002 Specialist handoff
Output / 003 Working artifact
  1. 01

    Set direction

    A person defines the goal, context, risk, and authority boundary.

  2. 02

    Route the work

    The right specialist receives a bounded task instead of a vague mandate.

  3. 03

    Exercise reality

    Agents use source, code, browsers, APIs, and infrastructure to produce the artifact.

  4. 04

    Leave a receipt

    Tests, links, releases, logs, or source records make the result inspectable.
