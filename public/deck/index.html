03 / Agent Launchpad

A private agent,
provisioned like software.

Agent Launchpad creates persistent personal agents with isolated workspaces, durable memory, tools, and working communication identities. The product is live as a controlled private preview.

Enter private preview ↗
01 / RuntimeIsolated workspace

Persistent files, snapshots, standby and resume keep the agent's working state without keeping compute hot.

02 / ContinuityDurable memory

Hermes memory and fresh-turn recall are provisioned on persistent storage and verified on a live agent.

03 / IdentityAgentMail inbox + messaging

A dedicated inbox, web chat, a phone messaging integration, and sender allowlisting give each agent a bounded working identity.

04 / PortabilityMulti-runtime

The primary runtime is live. A second provider passed inference, snapshot, stop/resume, and exact-session continuity canaries; rollout remains gated.
